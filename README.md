# VitaCraft

Мягкая воксельная игра в браузере: строишь деревню для смурфиков, потом побеждаешь
большого пушистого босса Витруляна. Ни одного внешнего ассета — вся графика и весь звук
генерируются кодом.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Другие команды:

```bash
npm run build      # прод-сборка в dist/
npm run typecheck  # tsc --noEmit
npm test           # юнит-тесты (vitest)
```

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` | идти, `Shift` — бежать |
| `Space` | прыжок (и всплывать в воде) |
| `ЛКМ` | ломать блок, а если ближе оказалась цель — ударить её |
| `ПКМ` | поставить выбранный блок |
| `F` | метнуть светящийся комок |
| `1`–`9`, колесо | выбрать блок в хотбаре |
| `F5` или `V` | сменить вид: от первого лица ↔ от третьего |
| `Esc` | пауза |

## Как проходить

**Испытание 1 — деревня.** Дом для смурфика это грибная кроватка (слот `1`) внутри
герметичной комнаты. Строй стены и крышу как хочешь, ставь кроватку внутрь — если воздух
никуда не утекает, приходит житель. Стекло считается стеной, так что окна делать можно,
а вот открытая дверь ломает герметичность. Сломаешь стену заселённого дома — житель
уйдёт; заделаешь обратно — приедет новый. Нужно 5 домов.

**Испытание 2 — Витрулян.** После пятой постройки наступает ночь и приходит босс.
Ключ к бою: **ударная волна от его прыжка бьёт только стоящего на земле**, поэтому от неё
уклоняются прыжком в момент, когда фронт до тебя доходит. Перед каждой атакой есть
телеграф — босс приседает перед прыжком и раскрывает пасть перед плевком. Постройки он
не разрушает.

Прогресс сохраняется в localStorage автоматически. На стартовом экране есть
«Начать заново».

## Устройство кода

```
src/
├── config/        палитра и все игровые числа — править внешний вид и баланс здесь
├── world/         блоки, чанки, мешер, терраген, воксельный рейкаст
├── player/        физика, ввод, ломание и установка блоков
├── entities/      база сущностей, смурфик, босс, снаряды
├── game/          валидатор домов, квест деревни, боевая система
├── render/        сцена и свет, модели существ, частицы, звук
└── ui/            HUD и полноэкранные карточки
```

Четыре решения, на которых держится вся картинка и геймплей:

1. **Vertex AO вместо текстур.** Мешер пишет цвет и запечённое затенение в атрибут вершин.
   Без AO соседние блоки одного цвета сливаются в неразличимую кашу. Природные блоки
   дополнительно получают разброс яркости на воксель, блоки для стройки — почти нет,
   поэтому постройки выглядят аккуратно, а мир — живо.
2. **Pointer lock включён в обоих видах.** Третье лицо это только смещение камеры, а не
   другая схема управления: переключение на вращение перетаскиванием ощущалось бы сломанным.
3. **Скруглённые формы только у существ.** Блоки мира остаются острыми кубами, живность
   собрана из `RoundedBoxGeometry` и покачивается — это и даёт «миленько» без ассетов.
4. **Дом = flood-fill от кроватки с лимитом.** Лимит и есть определение замкнутости:
   снаружи область бесконечна, значит выход за лимит означает «где-то дует». Проверка
   гоняется заново после каждого изменения блока рядом, в обе стороны.

Мир не сохраняется целиком: он детерминированно восстанавливается из сида, а в
localStorage идёт только дифф изменённых игроком блоков.

Основа воксельной части (мешер с отсечением граней, DDA-рейкаст) взята из официального
мануала Three.js и доработана под vertex colors.
